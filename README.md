# ほっとニュース

心が温まるニュース、希望が持てるニュース、くすっと笑えるニュースを、
日本と世界から毎朝お届けする小さなサイトです。

- 公開先: https://hotto-news.pages.dev/
- 構成: index.html（表示）＋ data.js（その日のニュースデータ）＋ build_static.py（静的記事の生成）
- 更新: 毎朝、data.js を差し替え（前日分は archive へ）→ `python3 build_static.py` を実行 → data.js と index.html の両方を push
- 静的記事: JS を実行しない AI クローラー向けに、その日の記事（見出し＋本文）を index.html 内の
  `<!-- static-articles:start -->` 〜 `<!-- static-articles:end -->`（noscript 内）にも持たせている。
  この区間は build_static.py が data.js から生成するので、手で編集しない。
  人間の見た目（見出し一覧＋ポップアップ）は従来どおり JS 描画。
- 火水四コマ: 見出し一覧の下・おまけの上に「火水四コマ」コーナーがある（2026-11-22分から）。
  index.html の静的セクション（`<!-- static-articles:end -->` の直後）として手で置いてあり、
  build_static.py の再生成範囲の外なので、毎朝の更新では消えない。
  四コマは1枚絵ではなく、コマごとの完成パネル画像4枚を縦一列に並べる形式（2026-11-21に変更）。
  パネル画像は日付名＋連番の WebP（例: yonkoma-20261122-w1.webp 〜 w4.webp、1200×900 の横長 4:3 を quality 85 で圧縮）。
  1枚目以外は loading="lazy"。締めの一言と署名は画像の帯ではなくページ側のテキスト表示。
  差し替えるときは、新しいパネル画像4ファイルを置き、index.html 内の `.yk-stack` の `src` 4か所と
  width/height、締めのテキストを差し替える。四コマの直下には絵本『ひーくんと みーちゃん』への小さなリンクがある。
  表示サイズは「ニュースが主役、四コマは脇役」のバランスで、幅70%（最大480px）・中央寄せに抑えている（2026-11-21調整）。
  パネルをタップすると拡大ポップアップ（`#ykBg`、howtoモーダルと同じ履歴連動方式）が開き、4枚を大きく読める。
  ポップアップ内にも同じパネル4枚＋締めの一言があるので、差し替え時はポップアップ側の `img` も一緒に差し替えること。
  パネルの作り方は yonkoma-20261122/build_yonkoma_wide_panels.py を参照（原画＋吹き出し文字入れをコマ単位で処理）。
  パネルは横長（4:3）が基準（2026-11-21に縦長から変更。縦長は1コマが大きすぎて全体が見にくかったため）。
- 四コマのNEWバッジ（2026-11-21追加）: 見出し横の小さな「NEW」ピル。セクション `#yonkomaBox` の
  `data-date`（掲載日）と今日の日付を JS が比べ、前後3日以内の時だけ表示する（初期状態は hidden）。
  差し替え時は `data-date` を新しい掲載日（YYYY-MM-DD）に書き換えること。それだけで、またNEWが出て、4日目から自動で消える。
- 四コマのアーカイブ「これまでの四コマ」（2026-11-21追加）: 最新1話＋過去最大5話の形。
  入口ボタン（`#ykArchive`）は過去分が1話も無い間は JS が hidden のままにし、1話以上たまると自動で出す（話数も自動表示）。
  過去分の画像は `data-src` で置き、入口を開いた瞬間に初めて読み込む（ページ表示時は読み込まない）。
  過去分のパネルもタップで拡大ポップアップが開く（ポップアップの中身がその話の4枚＋締めの一言に入れ替わる仕組み）。
  差し替え手順（NEWバッジの日付更新と合わせて一連の作業）:
  1. 新しい四コマを最新分として載せる（パネル画像・`.yk-stack` の src・締めのテキスト・ポップアップ側 img を差し替え）。
  2. セクションの `data-date` を新しい掲載日に更新する（NEWバッジ用）。
  3. 直前まで最新だった回を、`#ykArchiveBody` の先頭に `.yk-past` として追加する
     （ひな形は index.html 内の `#ykArchiveBody` 直下のコメント参照。タイトル＋日付＋パネル4枚（data-src）＋締めの一言）。
  4. アーカイブが5話を超えたら、一番古い `.yk-past` を外す（その話のパネル画像ファイルも削除してよい）。
- 四コマの「♡ほっとした」ボタン（2026-11-22追加）: 拡大ポップアップの最下部に、記事ポップアップと同じボタンがある。
  集計は記事と共通の仕組み（Supabase の hotto_likes＋increment_hotto_like RPC、localStorage の hotto-liked で1人1話1回、ハートが舞う演出も共通）。
  四コマ用IDは `yonkoma-YYYYMMDD` で、パネル画像名から自動生成される（最新話は1コマ目の画像名、過去話も同じ）。
  話の差し替え・アーカイブ追加のときにボタン側の作業は不要（画像名の日付を正しく付けるだけで、新しい話も自動で別カウントになる）。
  **同じ掲載日に2話目を出す場合**は、その話の画像名の日付の直後に英字サフィックスを付ける（例: `yonkoma-20261122r-w1.webp` → IDは `yonkoma-20261122r`）。
  日付だけだと先の話とIDが被って同じカウントになってしまうため（2026-11-22「雨の日」で実施）。`data-date` は実際の掲載日のままにする。
